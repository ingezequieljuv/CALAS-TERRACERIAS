# Compactación Terracerías

Formato F02-JUVISA-S507-01 · Registro ensaye determinación del grado de compactación (terracerías). App independiente de la Bitácora de Obra.

Página para instalar: https://ingezequieljuv.github.io/CALAS-TERRACERIAS/

- Se instala en la compu y en el iPhone con el ícono de JUVISA y abre sin señal (`sw.js`, `manifest.json`, `icon-*`).
- Guarda registros y fotos en el dispositivo; sin internet se quedan ahí y se suben solos al regresar la señal.
- Con un token de GitHub con acceso a este repositorio, los registros y fotos se respaldan en la rama `registros` (`registros.json` y `fotos/`) y se ven en todos los dispositivos.
